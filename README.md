# Text Game

## Описание

Простая текстовая игра на Go в стиле классических MUD (Multi User Dungeon), где игрок перемещается по комнатам, собирает предметы и выполняет задания.

## Запуск

```bash
go run main.go
```

## Тестирование

```bash
go test -v
```

## Поддерживаемые команды

- `осмотреться` - осмотреть текущую комнату
- `идти <комната>` - перейти в другую комнату
- `взять <предмет>` - взять предмет
- `надеть <предмет>` - надеть рюкзак
- `применить <предмет> <цель>` - применить предмет к объекту

## Требования

- Go 1.18+
